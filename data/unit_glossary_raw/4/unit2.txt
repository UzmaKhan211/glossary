C

common denominator when 2 or more fractions have the same denominator

common numerator when 2 or more fractions have the same numerator

H

hundredth the base-ten place value equal to 1/100. One hundredth is written as 0.01

T

tenth the base-ten place value equal to 1/10. One tenth is written as 0.1
